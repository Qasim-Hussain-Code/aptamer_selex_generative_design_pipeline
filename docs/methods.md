# Methods and decisions

This repository tests target-specific information from selection data. It does not claim that an aptamer can be reliably designed for an arbitrary target from protein sequence or structure alone. A generated molecule without an experimental measurement is a generated candidate.

The primary analysis retains all public rounds. TG2 rounds later than the round used in the original RaptRanker ranking remain included. The original article reports amplification of sequences with negative assay labels in those later rounds. This is a reason to retain frequency and enrichment as measured baselines rather than assume that late-round abundance is activity. The endpoint used for ridge fitting is final-versus-previous-round log2 enrichment. Assay logistic fitting uses the separate training assay partition. No held-out measurement enters either fit, early stopping, parameter selection or seed selection.

Primers and allowed length intervals are taken from Supplementary Tables S2/S3. They describe the transcribed strand and differ from the initial DNA template orientation in the main methods. An exact internal occurrence of the forward primer followed by the reverse primer delimits the variable region; leading barcode bases and trailing sequencer sequence do not enter features. Reads with ambiguous bases, primer failures, multiple anchors, out-of-range variable lengths or constant-region remnants have explicit rejection counts. The intervals retain biologically observed indels. These are exact primer filters and can reject true molecules whose primer was sequenced incorrectly. There is no quality-based correction or error collapsing.

There is an additional literal boundary discrepancy for Data2: the main article's PCR forward primer ends in `CAGAA`, while Supplementary Table S3's computational filter ends in `CAGAAG`. Orientation alone does not explain that added G. Processing follows S3, and assay strings remain exactly as published in S5. No alternative boundary was selected from test performance. Exact sequence recovery and count lookup depend on this convention.

Each round is counted with a bounded in-memory batch and an on-disk SQLite table. FASTQ structure, retained-depth reconciliation, sorted unique output and provider checksum are checked. Raw data are deleted after output verification. The first completed round supplies a measured compact/raw ratio and SQLite expansion factor. The projection includes all compact tables plus one raw file and its temporary count store with an added safety margin. The environment and package temporary files count toward the local footprint.

The model pool is the seeded hash subset of late-round sequences read at least twice. It is capped before evaluating models. This caps quadratic family construction, not the sequencing data. Assay sequences are added to the family graph even when absent from the training pool. Families are exact connected components of global normalized edit identity. The primary threshold is arbitrary, selected in configuration before model evaluation. Sensitivity thresholds use the same primary assay test IDs.

The fixed test set consists of a label-blind hash selection of assay families. The grouped arm excludes every training-pool member in any held-out component. The matched exact-only diagnostic shares those test IDs but excludes only exact test sequences. It is stored with strategy `random` for compatibility with the job schema and is explicitly named in prose. The additional `naive_sequence_random` arm selects assay test sequences independently by a seeded hash and permits relatives to cross the boundary. This arm was added after the first local execution to correct the diagnostic definition. No seed or metric was selected for performance. Its different test cases prevent a paired interpretation of its difference from the primary arm. The original diagnostic and all original test cases remain visible.

Some training assay sequences are absent from the eligible SELEX pool. Their labels can enter the assay-supervised model, but their sequences do not enter the SELEX generator's training pool. The manifest records assay-training eligibility separately from selection-pool membership. The evaluation sequences are identical across methods within an arm. Supervised and SELEX-only methods have different information inputs and are labelled by score definition.

The direct frequency and enrichment lookup arms become constant after exact test exclusion. These outcomes are retained. Full-count observed references are additionally reported and marked observational. They have seen test sequence identities through selection counts. They must not be described as strict unseen-sequence predictions or compared with generators as though exposure were identical.

Features and regularization are fixed in configuration. Structural descriptors are standardized within training data before fitting, as are k-mer features. Canonical RNA folding uses the complete assay construct except its poly(A) tether. No measured target-binding energy is calculated. No tertiary prediction runs.

The Markov null fits start, first-order transition and training length distributions with read-count weights and add-one nucleotide smoothing. A single fitted model supplies every generation seed. Raw draws, uniqueness, length, composition, exact copies, nearest training sequence, edit identity and test-family recovery are retained. Generation-seed variation does not estimate training-seed variation. Only the grouped primary arm generates the headline fixed-budget candidates.

Stage restart manifests hash configuration, inputs, scientific code and outputs, including generated tables. Changed content invalidates the relevant stage. FASTQ restart manifests separately validate provider MD5, primer configuration, compact counts and QC hashes. Final verification reuses verified full-data counts rather than downloading all reads twice. The clean clone runs the synthetic workflow and Python suite with the provisioned dependencies, without external research inputs or development caches. `--target` limits retrieval while the comparative report still requires both targets.

Scientific stages validate their hashes and skip. Provider metadata is revalidated; figures and reports rerender because the resource and failure logs gain new execution records.

The independent audit exposed a Windows permission conflict in pytest's shared global temporary/cache directories. Tests now create a fresh temporary directory within the measured project cache and remove only that resolved directory after the session. The pytest cache provider is disabled. The failed attempt remains in the failure/resource history.

Family bootstrap intervals report undefined single-class resamples. The confidence interval describes this test set and model fit; it does not include training-set or hyperparameter uncertainty. Small family counts and an unusually high positive prevalence limit discrimination. All targets, thresholds, seeds, constant scores, unavailable classifiers and omitted neural methods stay visible.
