# Score dictionary

Every ranking score is distinct from an experimental binding measurement. Machine-readable definitions are in results/score_dictionary.tsv and are regenerated by scripts/write_report.py.

Read frequency is count divided by the number of reads surviving filters in that round. Selection, amplification and sampling all affect it. Observed frequency queries an assay sequence in the original count table. It is an observational readout with sequence exposure. The harmonized frequency arm queries the filtered training table. Exact test sequences have been removed, so its test scores are zero. Its constant-score average precision equals test prevalence. Both arms remain visible.

Enrichment compares the final two sequenced rounds. With pseudocount a and V unique sequences in their union, it is `log2(((c_late+a)/(N_late+a*V))/((c_previous+a)/(N_previous+a*V)))`. Each round is normalized separately; zero counts remain finite. This differs from the paper's undefined zero-count ratio. The harmonized exact-lookup arm has zero test counts in both rounds and a constant score. Observed enrichment uses original counts. Neither predicts a dissociation constant.

K-mer ridge predicts log2 enrichment from normalized monomer, dimer and trimer frequencies with fixed regularization. It is supervised by SELEX enrichment, not SPR. The assay-supervised logistic model uses only training assay labels and reports a decision function. It is not a calibrated probability. Structural variants add the configured intramolecular folding descriptors to the same features and use the same test sequences.

The Markov model reports length-normalized log probability under a first-order, read-count-weighted nucleotide model with add-one smoothing. Sampling uses its fitted start and transition distributions and its observed training length distribution. This measures sequence distribution, not biological activity.

The hosted RaptGen adapter registers posterior-mean conditional PHMM log probability divided by sequence length. It uses upstream forward dynamic programming at the encoded posterior mean. This is a reconstruction quantity, not integrated VAE sequence likelihood, latent density or an activity-guided surrogate. No RaptGen score exists from this local run. No AptaDiff quantity is registered because its executable arm is excluded. Full mode cannot turn an unregistered diffusion objective into an assay prediction.

ViennaRNA MFE is intramolecular minimum folding free energy in kcal/mol with canonical-RNA Turner parameters at the configured temperature. The full assay construct without the poly(A) tether is folded. Base-pair count counts opening parentheses in the MFE structure; paired fraction is twice that count divided by construct length. Ensemble diversity is mean base-pair distance within the partition-function ensemble. These are a canonical-RNA secondary-structure proxy. Modification-specific parameters for the experimental 2'-fluoro pyrimidines were not used.

SPR response in RU and Positive/Negative labels come directly from primary Tables S4/S5. RU is the end-of-injection response, not KD. Higher response has the declared stronger-response direction. The published label is preserved; no new binary threshold is introduced. The paper's criterion is attributed in ground_truth_audit.tsv. A separate tested KD transformation is minus log10(KD), because smaller KD has stronger binding. No measured KD occurs in the evaluation tables.

Average precision is the noninterpolated sum of precision at each distinct score threshold weighted by its increase in recall. It is the primary binary endpoint and should be read alongside prevalence. AUROC is a secondary ranking endpoint. Spearman and Kendall correlate ranking scores with original RU. Constant-score correlation is undefined and remains labelled undefined. Top-k precision uses fractional inclusion at tied boundaries. No threshold is optimized on the test set.

Intervals resample sequence families with replacement. Resamples with only one class are counted and omitted from discrimination intervals; the retained fraction is reported. Paired differences use the same resampled test families for both methods. A family interval is not a sequence-level interval. The independent naive random partition changes test cases, so its case-mix difference cannot be interpreted as a paired leakage effect.

Edit identity is `1 - global Levenshtein distance / max(lengths)`. It is an edit-identity convention, not percent matches from a particular alignment. Exact connected components define families, including transitive chains. A generated candidate recovers a test family when it meets the same identity threshold to at least one experimental test sequence. Recovery is sequence neighbourhood coverage, not evidence that an untested molecule binds.
